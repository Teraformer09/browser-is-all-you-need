# Prime Intellect Mobile Android ADK Contract

This repo should be treated as a mobile Android APK/ADK environment package.

## Target

Primary target:

```text
mobile Android apps installed as APKs
```

Current reference APK:

```text
package: com.primeintellect.dummyrl
apk: dummy_android_app/build/out/dummy-rl-app.apk
```

## Environment Shape

The environment exposes the standard RL loop:

```text
reset() -> observation
policy.act(observation) -> structured action
step(action) -> next observation, reward, done, info
```

The Android execution backend can be:

```text
AndroidWorld AsyncEnv + JSONAction
ADB/UIAutomator direct control
```

The production-style path is AndroidWorld:

```bash
./scripts/run_android_world_openai.sh
```

## Action Format

Actions are structured JSON objects:

```json
{"action": "input_resource", "target": "search_input", "text": "airport ride"}
{"action": "click_resource", "target": "submit_button", "text": null}
{"action": "press_back", "target": null, "text": null}
{"action": "wait", "target": null, "text": null}
{"action": "finish", "target": null, "text": null}
```

Targets can be short resource names or full Android IDs:

```text
search_input
com.primeintellect.dummyrl:id/search_input
```

## Reward Format

Reward is generated by the APK state, not by the model.

The dummy APK writes durable task state to:

```text
shared_prefs/dummy_state.xml
```

The environment reads it with ADB `run-as` and computes:

```json
{
  "reward_components": {
    "query": true,
    "name": true,
    "email": true,
    "submitted": true
  },
  "reward": 1.0,
  "final_reward": 1.0,
  "success": true
}
```

## Artifact Format

The run script writes this Prime Intellect-style artifact bundle:

```text
artifacts/android_world_openai_run/
  rollout.jsonl
  summary.json
  result.json
  final_screen.png
  emulator_run.mp4
  emulator.log
  screenrecord.log
```

`rollout.jsonl` contains one JSON object per episode:

```json
{
  "episode": 0,
  "task": "DummyApkFormSearchTask",
  "goal": "...",
  "success": true,
  "reward": 1.0,
  "final_reward": 1.0,
  "steps": 9,
  "transitions": []
}
```

`summary.json` contains benchmark-level fields:

```json
{
  "run_status": 0,
  "model": "gpt-4o-mini",
  "adb_serial": "emulator-5556",
  "console_port": 5556,
  "grpc_port": 8554,
  "rollout_count": 1,
  "last_rollout": {
    "success": true,
    "reward": 1.0,
    "final_reward": 1.0,
    "steps": 9
  },
  "artifacts": {}
}
```

## Dummy APK Requirements For Future Apps

Any Uber-like, DoorDash-like, shopping, banking, or booking dummy APK should keep this contract:

```text
stable resource IDs
visible UI fields/buttons
explicit task goal
state persisted to SharedPreferences or another readable durable store
reward function based on exact durable state
benchmark variants separate from training variants
```

See `docs/app_guide.md` for the app design checklist.

## What Would Change For A Different Prime Intellect Schema

If Prime Intellect requires a different schema, do not change the AndroidWorld environment loop first. Change only:

```text
rollout serializer
summary/manifest writer
artifact naming/layout
```

The APK, ADB, AndroidWorld bridge, and reward function already fit the mobile Android ADK requirement.
